# Handcrafted Furniture Workshop Gallery

A responsive digital furniture gallery developed for the Prodesk IT client project.

## Features

- Responsive furniture gallery
- Search by furniture name, material, or category
- Loading indicator
- Empty-state message
- Contact form validation
- XSS-safe text handling
- Keyboard accessibility
- Responsive mobile layout
- Telemetry simulation using console logging
- Semantic HTML5 and vanilla CSS/JavaScript

## Technologies

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Vercel
